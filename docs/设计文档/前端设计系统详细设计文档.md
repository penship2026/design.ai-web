# 前端设计系统详细设计文档

## 1. 项目概述

### 1.1 项目背景
随着AI技术的发展，设计行业正在经历一场变革。本项目旨在开发一个集成AI大模型的纯前端设计系统，帮助用户快速生成网页设计方案，并提供预览和导出功能。

### 1.2 项目目标
- 实现用户与AI的对话功能，用户输入设计需求，AI生成设计方案
- 提供实时预览功能，支持不同屏幕尺寸的响应式设计
- 支持多种格式的代码导出（HTML、Vue组件、ZIP包）
- 采用模块化架构，便于维护和扩展
- 提供友好的用户界面和流畅的用户体验

### 1.3 技术栈
- **前端框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **数据持久化**: LocalStorage
- **AI模拟**: 配置化的延迟响应和模拟数据
- **文件导出**: FileSaver.js, JSZip

```

```

### 2.2 模块划分

| 模块 | 功能描述 | 文件位置 |
|------|----------|----------|
| 对话模块 | 用户输入设计需求，AI生成设计方案 | src/components/Chat/ |
| 预览模块 | 实时预览设计效果，支持多种屏幕尺寸 | src/components/Preview/ |
| 导出模块 | 支持HTML、Vue、ZIP格式的代码导出 | src/components/Export/ |
| 配置模块 | 系统配置管理（AI参数、导出格式、预览尺寸） | src/config/ |
| 状态管理 | 管理聊天记录、当前设计数据 | src/stores/ |

### 2.3 数据流
1. 用户在聊天界面输入设计需求
2. ChatComponent发送请求到模拟AI服务
3. AI返回设计数据（HTML、CSS、JS）
4. 设计数据存储到Pinia store
5. PreviewComponent监听store变化，更新预览
6. ExportComponent提供导出功能

### 3.2 预览功能

#### 3.2.1 功能描述
实时预览AI生成的设计方案，支持移动端、平板和桌面端的响应式设计。

#### 3.2.2 实现细节
- 使用iframe加载生成的HTML内容
- 提供屏幕尺寸切换按钮
- 响应式设计，自动调整预览区域大小

#### 3.2.3 关键代码
```javascript
// src/components/Preview/PreviewComponent.vue
const updatePreview = (designData) => {
  if (!previewIframe.value || !designData) return
  
  try {
    const iframeDoc = previewIframe.value.contentDocument || previewIframe.value.contentWindow.document
    const fullHtml = createHtmlContent(designData)
    
    iframeDoc.open()
    iframeDoc.write(fullHtml)
    iframeDoc.close()
    
  } catch (error) {
    console.error('预览更新失败:', error)
    ElMessage.error('预览更新失败，请检查设计代码')
  }
}
```

### 3.3 导出功能

#### 3.3.1 功能描述
支持将设计方案导出为HTML文件、Vue组件或ZIP包，方便用户进一步开发。

#### 3.3.2 实现细节
- 使用FileSaver.js实现单文件导出
- 使用JSZip实现ZIP包导出
- 支持自定义文件名

#### 3.3.3 关键代码
```javascript
// src/components/Export/ExportComponent.vue
const exportCode = async () => {
  if (!chatStore.currentDesign) {
    ElMessage.warning('请先生成设计方案')
    return
  }
  
  isExporting.value = true
  
  try {
    const designData = chatStore.currentDesign
    const format = selectedFormat.value

    switch (format) {
      case 'html':
        await exportAsHtml(designData, fileName.value)
        break
      case 'vue':
        await exportAsVue(designData, fileName.value)
        break
      case 'zip':
        await exportAsZip(designData, fileName.value)
        break
      default:
        ElMessage.error('不支持的导出格式')
    }
  } catch (error) {
    console.error('导出失败:', error)
    ElMessage.error('导出失败，请重试')
  } finally {
    isExporting.value = false
  }
}
```

## 11. 总结

本前端设计系统实现了一个集成AI大模型的网页设计工具，提供了对话、预览和导出三大核心功能。系统采用模块化架构，使用Vue 3、Element Plus等现代前端技术栈，具有良好的用户体验和扩展性。

系统的主要特点包括：
- 友好的聊天界面，支持自然语言输入设计需求
- 实时预览功能，支持响应式设计
- 多种格式的代码导出，满足不同开发需求
- 配置化管理，便于系统定制和扩展
- 数据持久化，确保用户数据不丢失

该系统为网页设计师和开发者提供了一个高效的设计工具，可以显著提高设计效率和开发效率。
